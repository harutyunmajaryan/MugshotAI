## 🧭 Overview

MugshotAI is a forensic witness-statement matching system. It processes eyewitness accounts and queries an existing MySQL database to find potential suspect matches.

Eyewitness descriptions are rarely certain, so each feature is quantified on a confidence scale from 0 to 100. MugshotAI translates these probabilistic descriptions into targeted, parameterized SQL queries, parses the feature criteria, and filters records to surface likely matches.

## ⚙️ How it works


1. **Witness statement:** the eyewitness description, with a confidence percentage for each feature.
2. **Statement parser:** reads nested data structures (such as dictionary-wrapped sets) and validates their types.
3. **Query builder:** turns the criteria into parameterized SQL statements.
4. **MySQL database:** queried through `mysql-connector-python`.
5. **Candidate matches:** records that fit the description are filtered and returned.

## 🔍 Example

A simplified illustration of the query pattern: parameterized SQL, a bounded result slice, and guaranteed cleanup. Table and column names here are placeholders.

```python
import mysql.connector
from mysql.connector import Error


def find_matches(criteria, limit=10):
    connection = None
    try:
        connection = mysql.connector.connect(
            host="localhost",
            user="your_user",
            password="your_password",
            database="your_database",
        )
        cursor = connection.cursor(dictionary=True)

        # Values are passed separately from the SQL text (no string formatting)
        query = "SELECT * FROM suspects WHERE hair_colour = %s AND build = %s"
        cursor.execute(query, (criteria["hair_colour"], criteria["build"]))

        return cursor.fetchall()[:limit]  # bounded result set
    except Error as err:
        print(f"Database error: {err}")
        return []
    finally:
        if connection is not None and connection.is_connected():
            connection.close()
```
